# Task 2: User Authentication Form

## Description
A login form implemented with HTML, CSS, and JavaScript. Includes client-side validation for email format and password length. Users can be added after successful authentication.

## Features
- Email format validation
- Password length validation
- Interactive login form
- User addition simulation (client-side)

## How to Run
1. Open `index.html` in a browser.
2. Enter email and password to test the validation.
